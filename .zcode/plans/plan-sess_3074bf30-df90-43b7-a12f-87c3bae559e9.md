## Hack Guard Upgrade — Image Support + Backfill Prune

### Problem
Current Hack Guard only tracks `message.content` (text). Image-only or attachment-only spam bypasses detection. Also, messages arriving before bot processes them (or skipped during concurrent burst) survive — no backfill sweep.

### Changes — all in `src/index.js`

#### 1. Spam Signature Builder (new helper function)
Extract spam key from any message type:
```
function buildSpamSignature(message) {
  const text = message.content?.trim() || '';
  const attachments = [...message.attachments?.values() || []]
    .map(a => a.proxyURL || a.url)
    .sort()
    .join('|');
  const stickers = [...message.stickers?.values() || []]
    .map(s => s.id)
    .sort()
    .join('|');
  const embeds = message.embeds?.length || 0;
  return `${text}::${attachments}::${stickers}::${embeds}`;
}
```
- Text message → keyed by content (same as before, backward compatible)
- Image/attachment spam → keyed by proxyURL|url sorted
- Sticker spam → keyed by sticker ID
- Empty content + no attachments → unique signature (won't false-trigger)
- Result: any identical message type across 3+ channels triggers

#### 2. History Track — store signature instead of raw content
Replace `content: message.content` with `signature: buildSpamSignature(message)` in the history push. Update detection loop to group by `item.signature` instead of `item.content`.

#### 3. Backfill Prune — sweep channels after initial deletion
After deleting all tracked spam items, **before** resetting history, fetch recent messages from each involved channel and delete any with matching signature:

```
// Collect unique channels involved in spam
const involvedChannelIds = [...new Set(allSpamItems.map(i => i.channelId))];

// For each channel, fetch last ~20 messages and delete leftovers
for (const channelId of involvedChannelIds) {
  const ch = message.guild.channels.cache.get(channelId);
  if (!ch?.isTextBased?.()) continue;
  try {
    const recent = await ch.messages.fetch({ limit: 20 });
    for (const [msgId, msg] of recent) {
      // Skip bot's own warning message + already-deleted messages
      if (msg.author.id !== userId) continue;
      if (msg.id === message.id) continue; // current message already deleted
      if (buildSpamSignature(msg) === spamSignature) {
        await msg.delete().catch(err => {
          if (err.code !== 10008) logger.debug(...);
        });
      }
    }
  } catch (err) { logger.debug(...); }
}
```

This catches:
- Messages that arrived before bot started processing
- Messages skipped during concurrent handler interleaving
- Any leftover identical spam in the 3+ channels

### Backward Compatibility
- Text-only spam: same behavior, signature = content string + `::||::0`
  - Wait — this breaks exact match. Fix: if no attachments/stickers/embeds, signature = content only. Full signature only when attachments present.

### Flow After Upgrade
```
msg3 (image) arrives → signature built → 3 unique channels match → trigger
  → lock user
  → delete tracked items (history)
  → backfill: fetch 20 recent msgs from each involved channel, delete matching signature
  → reset history
  → warning + timeout
  → unlock
msg4 arrives during processing → lock active → delete immediately
```

### No Breaking Changes
- Text spam detection unchanged (signature = content when no attachments)
- Warning/timeout logic untouched
- `userSpamLock` race-condition fix from previous edit preserved
- Stale-lock cleanup in health check preserved
